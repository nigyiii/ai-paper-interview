# 生成式 AI 论文与算法工程师面试准备

围绕 3D 生成、视频生成和视觉内容生成，持续整理最新论文解读与 AI 算法工程师面试问答，关注游戏、机器人仿真和内容创作中的实际应用。

面试知识范围包括具身智能、3D Gaussian Splatting（3DGS）、图像生成、视频生成、VLA、强化学习和世界模型，兼顾数学原理、PyTorch 实现和工程设计。

## 更新安排

- 生成任务：ChatGPT 中的「生成式 AI 论文与面试周报」。
- 时间：每周一上午，北京时间（Asia/Shanghai）。
- 首期计划：2026-09-14。
- 准备周期：前 12 周完成核心覆盖，后 12 周进阶强化；随后继续论文跟踪和综合复习，直到调整任务。
- 每期正文：`weekly/YYYY-MM-DD.md`，日期按北京时间该期所属周的周一确定。
- 同步目标：本仓库的 `main` 分支。每次生成后提交完整文档，并更新下方索引。
- 定时调度由 ChatGPT 任务执行，本仓库用于保存和查阅文档。

## 每期内容

### 论文精选与解读

精选 3–5 篇论文，重点解读其中 2 篇。优先检索过去 7 天首次公开或有实质更新的研究；数量不足时，可扩展至最近 30 天并明确标注。经典论文单独作为背景材料。

每篇提供已核实的原文及可用的代码/权重链接。重点论文解释问题、方法差异、表示方式、架构与数据流、训练目标、关键公式、推理过程、实验和消融、局限、复现成本，以及游戏、仿真和内容创作中的应用价值。

解读以论文原文和官方资料为依据，区分已验证结论与推断，不将视觉逼真直接视为几何或物理正确。

### 面试问题与答案

每期 8–10 道题，包括至少 1 道 Python/PyTorch 实现题和 1 道工程/系统设计题，并安排论文关联题和跨主题复习题。

每题包含考查点、简明回答、深入解释、追问及答案和常见误区。实现题提供参考代码与关键张量形状；系统设计题说明需求假设、方案、评估和取舍。

### 学习任务

提供 3–5 项精读、推导、编码或口头回答练习，说明优先级、建议用时和下期主题。计划不代表已经完成的学习记录。

## 文档与版本约定

- 周报使用 UTF-8 Markdown；行内公式使用 `$...$`，独立公式使用 `$$...$$`，避免将公式放入代码块。
- 每期标明期号、所属周、生成/更新日期、论文检索时间范围、面试主题和参考资料。
- 同一期重试或修订更新原文件，保留 Git 历史，不创建重复期次；无内容变化时不提交。
- 同步时保留已有历史文档与人工笔记，并基于最新版本更新索引。
- 只有远端文件内容确认成功写入后，任务才报告同步成功并提供链接。
